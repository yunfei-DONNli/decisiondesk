# 智策台 DecisionDesk 设计系统

## 产品表面
- 应用壳：三栏桌面工作台
- 结果页：HTML 决策报告预览
- 配置页：自动化、通知、语言与基础设置

## 美学方向
- 专业交易工作台风格
- 浅色底、清晰层级、卡片化结果表达
- 用户应感知为专业判断工具，而非聊天产品

## 设计 token
- 背景：浅灰白体系
- 表面：白色卡片与浅边框
- 主色：绿色用于正向决策与完成状态
- 风险色：红色用于止损、失败、利空
- 中性色：灰蓝用于过程与辅助信息
- 圆角：中等圆角，避免过度消费级 UI

## 布局策略
- 固定三栏：任务 / 过程 / 结果
- 左栏偏导航与状态，中栏偏过程，右栏偏交付物
- 结果页首屏先展示状态卡，再进入图表与详细分析

## 组件与模式
- 必备组件：任务列表、角色列表、状态徽标、结果主卡、图表卡片、资料项、通知项
- 谨慎使用：大面积渐变、夸张阴影、无意义动效

## 状态覆盖
- 任务：排队中 / 分析中 / 已完成 / 失败
- 结果：五段推荐状态 + 风险等级 + 更新时间
- 通知：桌面通知、应用内消息、通知代理状态

## 记忆点
- 结果页顶部的大状态卡 + 三栏工作台 + 本地 HTML 预览

## 动效策略
- 以状态反馈和切换引导为主
- 图表交互支持中度反馈
- 首版不做暗色模式

## 无障碍要求
- 中英文双语界面
- 完整焦点态
- 键盘可达
- 关键界面支持基础屏幕阅读器兼容

## 内容语气
- 专业、克制、明确
- 给结论但不煽动
- 风险、条件、时间语义必须完整

## 禁止事项
- 禁止使用“稳赚”“必涨”“抄底机会”等诱导表达
- 禁止把工作台做成聊天主视图
- 禁止把风险信息折叠到不可见层

## 约束定义
- 首屏主状态卡信息不超过 6 个核心字段
- 左栏一级导航固定 4 项
- 单次多股对比默认上限 5 只

## 实现备注
- 设计 token 映射到前端主题变量
- 结果页需同时适配应用内预览与导出 HTML
