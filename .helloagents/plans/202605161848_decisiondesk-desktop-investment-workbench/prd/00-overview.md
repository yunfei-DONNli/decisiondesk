# 智策台 DecisionDesk — 产品概述

## 产品愿景与定位
- 打造一个面向个人投资研究者的桌面投研工作台，通过官方专家团队协作，生成结构化投研报告与交易决策卡，帮助用户更快完成股票判断、跟踪与比较。

## 目标用户画像
- Persona 1：个人投资研究者 — 高频分析 A 股、港股、美股，重视结论质量、风险提示与时间效率。
- Persona 2：研究型内容创作者 — 需要把研究过程快速转为结构化交付物与可复用分析版本。

## 用户痛点与机会
- 单人分析过程碎片化，技术面、基本面、新闻面、情绪面难以统一。
- 缺少稳定可追溯的分析工作流，结果易散落在聊天记录和零散笔记中。
- 持续跟踪和版本回看成本高，难以理解判断何时发生变化。

## 成功指标
- [ ] 首要指标：分析任务完成率 — 目标值：首轮核心闭环可稳定完成
- [ ] 次级指标：结果页可读性与一致性 — 目标值：主状态卡、报告、图表和风险提示表达一致

## 项目范围
- macOS 桌面应用
- 单股深度分析
- 自选股持续跟踪
- 多股横向对比
- 官方投研团队协作
- 本地保存与 HTML 导出

## 非目标
- 不做投资顾问服务
- 不承诺收益
- 首版不做账号必需和云同步
- 首版不做用户自由组队和通用工作流编排器
