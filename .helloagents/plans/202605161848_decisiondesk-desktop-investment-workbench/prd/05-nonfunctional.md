# 智策台 DecisionDesk — 非功能需求

## 性能
- 单股分析主流程需在可接受时间内完成
- 结果页打开与本地 HTML 预览应保持流畅
- 自选股列表与状态卡的准实时刷新不得显著阻塞工作台

## 稳定性
- 失败任务必须可查看原因并支持重新分析
- 自动重评估需具备基本调度可靠性

## 安全与隐私
- 本地保存为主
- 仅将模型调用、数据获取、联网检索所需信息外发
- 不默认做云端托管用户任务历史

## 可扩展性
- 通知系统需支持通知代理扩展
- 数据源与模型通道需保留后续替换能力

## 可观测性
- 记录任务状态、更新时间、失败原因、导出结果路径
- 自动化模块需记录调度执行情况与通知投递状态
