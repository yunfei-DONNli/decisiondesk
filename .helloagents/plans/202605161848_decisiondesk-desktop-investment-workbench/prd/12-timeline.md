# 智策台 DecisionDesk — 里程碑与排期

## 阶段划分
| 阶段 | 范围 | 目标 |
|------|------|------|
| MVP | T01-T07：三栏工作台、股票识别、Multica + Codex 官方团队、结果页、HTML 导出、本地保存、重新分析与历史版本 | 验证核心分析闭环 |
| V1 | T08-T13：多股对比、自选跟踪、通知代理、双语、丰富图表、持仓增强、合规完善 | 形成完整桌面投研工作台 |
| V2 | 暗色模式、Windows、分享发布、更强证据展开 | 扩展平台能力与传播能力 |

## 里程碑与交付物
- M1：工作台骨架与任务主链 — 交付物：三栏工作台、任务状态、结果页主卡
- M2：Multica 集成与单股分析闭环 — 交付物：标的识别、官方团队、AnalysisResult 契约、HTML 报告、本地预览
- M3：跟踪与对比能力 — 交付物：自选股、自动重评估、多股对比、准实时价格提示
- M4：体验与合规完善 — 交付物：双语、通知代理、免责声明、图表增强、持仓增强

## 依赖关系与风险
| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| Multica 自托管环境不稳定 | 影响任务调度与进度流 | 中 | 优先完成本地 Docker + PostgreSQL 验证与健康检查 |
| 数据源稳定性不足 | 影响分析质量 | 中 | 设计 AkShare / yfinance fallback 与缓存 |
| 本地执行资源占用偏高 | 影响桌面体验 | 中 | 控制并发、分层刷新、缓存中间结果 |
| 开放联网分析结果噪音 | 影响可信度 | 中 | 强化来源摘要、风险裁决与结果质检 |

## 资源需求
- 桌面前端开发
- Multica 自托管环境（Docker + PostgreSQL）
- Codex Agent 配置与 Prompt 契约
- 数据接入与分析策略设计
- 产品与设计协同打磨结果页
