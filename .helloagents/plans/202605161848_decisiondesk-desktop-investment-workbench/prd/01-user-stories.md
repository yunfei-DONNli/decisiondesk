# 智策台 DecisionDesk — 用户故事

## 核心用户旅程
- 输入股票代码、名称或自然语言问题
- 系统识别标的，必要时让用户确认
- 自动启动官方投研团队分析
- 执行中查看协作过程
- 完成后查看状态卡与结构化报告
- 将股票加入自选并持续跟踪

## 用户故事
- 作为个人投资研究者，我希望输入“帮我分析一下小米”，系统先确认标的，再直接开始完整分析。
- 作为个人投资研究者，我希望结果页先给出五段推荐状态和操作建议，再查看详细依据。
- 作为跟踪用户，我希望同一只股票每次重评估都保留独立历史版本，便于回看变化。
- 作为选股用户，我希望输入“帮我对比一下白酒龙头”，系统先生成候选池并允许我删改后再对比。
- 作为谨慎用户，我希望每份结果都带风险提示和免责声明。

## 边缘场景
- 自然语言识别到多个候选股票时，需弹出候选列表确认。
- 盘中价格变化显著，但完整分析仍基于最近一次评估时，需明确标注差异。
- 任务失败时，用户需能看到失败原因并直接重新分析。

## 验收标准
- 股票识别流程可处理代码、名称、自然语言三类输入。
- 任务完成后必须生成结构化结果页与本地 HTML 文件。
- 同一股票的重评估结果必须保留为独立历史任务。
