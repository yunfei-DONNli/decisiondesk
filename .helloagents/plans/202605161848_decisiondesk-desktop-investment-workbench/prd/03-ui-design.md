# 智策台 DecisionDesk — UI / UX 设计

## 整体风格
- 专业交易工作台风格
- 浅色底、清晰分栏、较高信息密度
- 强调“结果判断工作台”，弱化聊天产品感

## 主布局
- 左栏：任务 / 专家 / 资料库 / 自动化
- 中栏：任务主线程、过程消息、文件产物、操作按钮
- 右栏：内嵌浏览器预览 HTML 结果页

## 结果页结构
- 顶部决策卡：推荐状态、操作建议、目标价、止损位、建议仓位、当前价格、分析时间
- 中部：综合评分、价格走势、多空对比、风险三角、关键指标表
- 下部：催化剂时间表、数据来源说明、免责声明

## 图表策略
- 首版保留丰富图表
- 交互层级为中度交互：hover、图例、时间切换、维度切换、局部展开

## 分析中体验
- 分析执行中默认展示协作过程页，而不是空白结果页
- 中栏优先采用时间线 / 列表结构展示阶段进度，而非卡片堆叠
- 必须展示当前阶段、角色名称、角色状态、关键中间结论
- 建议提供“阶段进度 + 角色名称轮播”作为等待反馈

## 结果页交互
- 固定“重新分析”按钮
- 点击后创建新任务历史，并在完成后自动打开新结果
- 若显示实时价格，必须同时提示分析基于最近一次完整评估

## 模式与可用性
- 首版不做暗色模式
- 中英文双语界面
- 键盘可达、清晰焦点态、屏幕阅读器基础兼容

## 术语约定
- 统一使用“决策卡”指代结果页顶部主状态卡
- 统一使用“投研团队”指代官方固定专家团队
